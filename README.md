* HW1: 基础回归模型 - 探索了文本特征提取（句子数、短语数）与线性回归。
* HW2: 自然语言处理初探 - 使用了 FastText 和词向量处理韩语/英语文本。（注：模型文件较大，未上传至仓库）
* HW3: 深度学习进阶 - 正在进行中的 PyTorch 神经网络实践。
Practice: 零散的知识点实验代码。

## 环境配置
为了运行本仓库的代码，你需要安装以下依赖：
```Bash
pip install torch torchvision pandas numpy scikit-learn
```
或者直接使用：
```Bash
pip install -r requirements.txt
```
